# Examples
This directory contains examples of Multiblocks that can be implemented with CTMB.
You're free to learn from, copy and modify these examples to create your own multiblocks.

- Melter - a simple production multiblock that turns obsidian into lava, and iron ingots into molten iron
- Induction Furnace - a more advanced production multiblock that can smelt multiple items at the same time, it needs to heat up in order to work
- Cargo Crane - a demonstrator of AMT Tactile hitboxes, that can pick up, hold and place blocks.  Controlled via Data or its GUI 
- Elevator - a multiblock that has no GUI, but can be controlled via Data or hand interaction
- Stargate - a multiblock that can teleport entities to a different dimension, controlled via Data or its GUI
